# 競合店リサーチ（クラウド版）セットアップ手順

PCを付けていなくても、毎朝クラウドで「競合店_入力」タブの分を記録・分析します。
ご自身の作業は「店のページを開く → ブックマークを押す → シートに貼る」だけです。

## 1. GitHub にスキルをアップロード（初回のみ）

1. ブラウザで GitHub のリポジトリ **ai-management-shopee** を開く
2. 「Add file」→「Upload files」
3. zip を展開した中の **`.claude` フォルダごと** ドラッグ＆ドロップする
   - アップロード後、`.claude/skills/competitor-research/` の中に `SKILL.md`・`config.json`・`shops.csv`・`scripts/`（2つの .py）があることを確認
   - `.claude` フォルダが見えない場合は、エクスプローラーの「表示」→「隠しファイル」にチェック
4. 下の「Commit changes」を押す（main ブランチに直接でOK）

## 2. ルーティンを作成（初回のみ）

Claude Code Desktop の「ルーティン」→ 新規作成（クラウドで実行するタイプ）。既存の「Shopeeリサーチ自動化（クラウド）」と同じ要領です。

| 項目 | 設定 |
|---|---|
| 名前 | Shopee競合店リサーチ（クラウド） |
| リポジトリ | ai-management-shopee |
| 実行環境 | Shopeeリサーチ環境（amazon.co.jp を許可済みのもの） |
| コネクター | **Google Sheets（書き込み用）** のみ（Google Drive は不要） |
| スケジュール | 毎日 5:00（JST）※ 3:00 リサーチ、4:00 出品ファイル作成の後 |

指示文（そのまま貼り付け）：

```
competitor-researchスキル（.claude/skills/competitor-research/SKILL.md）の手順どおりに実行してください。
Google Sheets「Shopeeリサーチ」の「競合店_入力」タブのうち未記録の分を「競合店_売れ筋」タブに記録し、Amazon.co.jp照合（「未検証」の再照合を含む）まで行ってください。
日付は必ずJST（Asia/Tokyo）基準で判定してください。
Google Drive・Google Sheets のファイル・タブ・行の削除やゴミ箱移動は絶対にしないでください。「競合店_入力」タブは編集しないでください。
無人実行なので質問や確認はせず、問題があれば「競合店_実行ログ」タブに書いて終了してください。
```

## 3. ブックマークを登録（初回のみ）

zip の中の `bookmarklet/install_bookmarklet.html` をダブルクリックで開き、オレンジのボタンを Chrome のブックマークバーへドラッグします。

## 4. 毎日の作業

1. Chrome で競合店のページを開き、「Top Sales（売れ筋）」で並べ替える
2. ブックマークバーの「Shopee売れ筋コピー」を押す（自動でスクロールして読み取り、コピーされる）
3. スプレッドシート「Shopeeリサーチ」の「**競合店_入力**」タブで、**A列の一番下の空いている行**をクリックして Ctrl+V
4. 翌朝 5:00 に自動で「競合店_売れ筋」「競合店_Amazon照合」に反映される

## 5. 初回テスト

1. 1店分を貼り付ける
2. ルーティンの「今すぐ実行」を押す
3. 「競合店_売れ筋」に今日の日付の行が増えていれば成功。うまくいかなければ実行ログ（ルーティンの実行履歴）を Claude に見せてください

## 前の版（PCで動かす版）について

PC用の `run_competitor_research.bat` と `data\competitor\inbox` は今後使いません。タスクスケジューラに登録していなければ、そのまま置いておいて大丈夫です。
