# Shopee → Amazon.co.jp 商品リサーチ

## 目的

Shopeeの東南アジア4カ国（シンガポールSG／フィリピンPH／マレーシアMY／タイTH）で今トレンドになっている商品を調査し、日本のAmazon.co.jpで自分が出品できそうな商品を各国3品ずつ発掘して、Google Sheetsに記録する。

## 対象国

- SG（シンガポール）
- PH（フィリピン）
- MY（マレーシア）
- TH（タイ）

## 選定基準

- **価格帯**：Amazon.co.jp販売価格でおおよそ3,000円〜10,000円を中心に探す（多少の前後は許容）
- **配送条件**：Amazon.co.jpで「翌日お届け」（お急ぎ便・Prime対応等で翌日発送・翌日到着が可能）な商品を優先する。翌日発送に対応していない商品は原則候補から除外する
- **優先順位**：トレンド性（人気の勢い・話題性・売れ行きの伸び）を最優先で評価する。価格差の大きさや競合の少なさは参考情報として記録するが、選定の主軸はトレンド性とする
- **商品カテゴリ・ブランド制限**：特になし。ノーブランド／有名ブランド問わず候補に入れてよい
- **除外するもの**：
  - 食品・化粧品・医薬部外品など、輸入や国内販売に法的な許可が必要なもの
  - 極端に大きい・重いもの
  - **PSEマーク表示義務がある商品**（リチウム電池・モバイルバッテリー・電源アダプター等、電気用品安全法の対象品）
  - **技適マーク表示義務がある商品**（Bluetooth・WiFi等の無線通信機能を持つもの：ワイヤレスイヤホン、スマートウォッチ、モバイルWi-Fiルーター等）
  - 正規ライセンス品・キャラクターグッズなど、並行輸入や真贋表示の問題が生じやすいもの（POP MART等のブラインドボックス系を含む）
  - **Amazon在庫切れの商品**：Amazon.co.jpの商品ページで「現在在庫切れです」「一時的に在庫切れです」「入荷時期は未定です」等の表示があり、カートに入れられない商品は候補から除外する

## 日付・タイムゾーンに関する重要ルール

本スキル内で「今日」「本日」「実行日」を判定・記録する際は、**必ず日本時間（JST, UTC+9）を基準とすること**。

実行環境のシステム時刻やツールが返す日時がUTC等JST以外のタイムゾーンである場合でも、そのまま使わず、必ずJSTに変換してから「今日の日付」を求めること（例：UTCの日時に9時間を加算してJSTの日付を算出する）。特に日本時間の深夜0時〜早朝9時台に実行される場合、UTCとJSTで日付が1日ズレるため注意が必要（このズレにより、実際にはまだ記録していない日を「記録済み」と誤認識し、リサーチをスキップしてしまう不具合が過去に発生した）。

## 手順

### 0. 過去の記録を確認する（新規性の担保）

リサーチを始める前に、Google Sheetsの既存データ（直近14日分程度）を読み込み、すでに記録済みの商品名・ASINを把握しておく。これは「同じ商品ばかりが毎日出てくる」ことを防ぐための重要なステップ。

このとき「本日分はすでに記録済みか」を判定する基準日は、上記ルールに従い**JSTの今日の日付**とする。UTC基準で判定しないこと。

### 1. Shopee側のトレンド調査（国ごと）

各国について、Web検索でトレンド情報を集める。同じ検索語ばかりだと同じ古い記事しかヒットしないため、次の2つの工夫をする。

**a. 検索語に「直近の日付」を必ず含める**（今日の年月、または「今週」「this week」など）。1ヶ月以上前に書かれた記事に依存しすぎない。

**b. カテゴリを日替わりでローテーションする**。曜日ごとに重点カテゴリを変え、リサーチの視点自体を毎日変える。

| 曜日 | 重点カテゴリ例 |
|---|---|
| 月 | 生活雑貨・収納 |
| 火 | ファッション・アパレル |
| 水 | ガジェット・電子小物（※PSE/技適対象は除外） |
| 木 | ビューティー・パーソナルケア雑貨（化粧品そのものは除く） |
| 金 | ペット用品・キッズ用品 |
| 土 | アウトドア・トラベル用品 |
| 日 | キッチン・インテリア雑貨 |

この曜日は目安であり、その日の実際のトレンドが別カテゴリに偏っていれば、無理にカテゴリに合わせなくてよい。あくまで「検索の切り口を毎日変える」ためのガイドとして使う。曜日の判定も、上記ルールに従いJST基準で行うこと。

検索例：
- 「Shopee [国名] trending [重点カテゴリ] [今年今月]」
- 「Shopee [国名] best seller [重点カテゴリ] this week」
- 「Shopee [国名] viral product [今年今月]」
- SNSやローカルニュースで話題になっている商品情報も参考にする

商品名・カテゴリ・現地価格・人気の根拠（レビュー数、話題性、売上の伸びなど）をメモしながら、1カ国あたり10件前後の候補を集める。

### 2. 出品可否の一次フィルタ

「除外するもの」の基準に沿って、候補から明らかに扱えないものを除く。あわせて、ステップ0で確認した既存記録と照らし合わせ、**すでに記録済みの商品は原則候補から外す**（明確に新しい根拠がある場合を除く。詳細はステップ4）。

### 3. Amazon.co.jpとの照合

残った候補ごとに、Amazon.co.jpを検索し、該当商品ページを実際に開いて（Fetchして）以下を確認する。検索結果の要約だけでは在庫状況までわからないため、必ずページ本体を確認すること。

- 同一または類似商品がすでに販売されているか
- **在庫状況**：商品ページで「現在在庫切れです」「再入荷予定は立っておりません」等の表示がないか確認する。在庫切れの場合はその候補を除外する
- **翌日発送の可否**：商品ページでお届け予定日（お急ぎ便・Prime表示等）を確認し、翌日発送・翌日到着に対応しているか確認する。対応していない場合はその候補を除外する
- Amazon.co.jp販売価格
- 出品者数・レビュー数（競合状況の参考値として）
- 商品ページのURL
- **ASIN**（商品ページURL中の `/dp/XXXXXXXXXX` または `/gp/product/XXXXXXXXXX` の10桁部分）。日本で仕入れる際の商品特定に使うため、必ず記録する

見つからない商品、または在庫切れの商品は候補から除外し、代わりの候補を探す。

### 4. 各国3品を選定

「選定基準」に従い、トレンド性を最優先にしつつ、価格帯（3,000〜10,000円）に収まるものを中心に、国ごとに最も有望な3品を選ぶ。

**新規性のルール**：
- 基本方針として、ステップ0で確認した「直近14日以内に記録済みの商品」は選ばない
- 例外として、明確に新しい根拠（新しいレビュー急増、新しいメディア掲載など）があり、かつその国でどうしても他に有望な候補が集まらない場合のみ、既出商品を再度選んでよい。その場合はメモ欄に「継続トレンド（再掲）」と明記する
- 1回の実行につき、4カ国合計12品のうち、再掲は最大2〜3品までを目安にする（大半は新しい商品にする）

### 5. Google Sheetsへの記録

指定のGoogle Sheetsに、以下の列で1商品1行ずつ追記する（ヘッダーがなければ最初に作成する）。

| 列名 | 内容 |
|---|---|
| 日付 | 実行日（YYYY-MM-DD、**JST基準**） |
| 国 | SG / PH / MY / TH |
| Shopee商品名 | 現地での商品名 |
| Shopee価格 | 現地価格（現地通貨表記のままでよい） |
| Shopeeリンク | 商品ページまたは参考情報のURL |
| トレンド根拠 | なぜトレンドと判断したか（簡潔に） |
| Amazon商品名 | Amazon.co.jp上の商品名 |
| ASIN | Amazon.co.jpの商品ページURLに含まれる10桁の商品コード（例：B0C73QT8D2）。仕入れ・出品時の商品特定に使う |
| Amazon価格 | 円 |
| Amazonリンク | 商品ページURL |
| 出品者数目安 | わかる範囲で |
| メモ | 補足・注意点など（再掲の場合は「継続トレンド（再掲）」と記載） |

同日中にすでに実行済みの場合は、重複追記せずスキップしてよい（1日1回分の記録で十分なため）。この「同日」の判定は、上記ルールに従い**必ずJSTの日付**で行うこと（UTC基準で判定し、まだJSTでは記録していない日を「記録済み」と誤判定してスキップしないよう特に注意する）。

## 出力時の注意

- Shopeeの現地価格とAmazon.co.jp価格は通貨が異なるため、円換算はしなくてよい（メモ欄に目安を書く程度で十分）
- 情報源のURLが取得できない場合は、検索クエリや情報源の名称をメモ欄に残す
- 4カ国×3品＝合計12行を目安に、実行のたびに記録する
